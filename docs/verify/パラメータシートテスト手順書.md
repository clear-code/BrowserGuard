# Chronos BrowserGuard パラメータシートテスト手順

## テスト対象モジュール

`docs\parameter-sheet.xlsm`

■ このブックは `tools\parameter-sheet\make-parameter-sheet.ps1` が生成する。
  出力処理のマクロは `tools\parameter-sheet\ExportConfig.bas` である。
  不具合を見つけた場合は、ブックではなくこれらを修正してブックを作り直す。

## 準備

* Microsoft Excel をインストールする
* `docs\parameter-sheet.xlsm` を作業用のフォルダー（例：`C:\BrowserGuardTest\parameter-sheet\`）にコピーする
  * 以下のテストはすべてコピーしたブックで行う
  * ※出力先がブックと同じ場所になるため、リポジトリ内に出力ファイルを残さないようにする
* コピーしたブックを Excel で開き、「コンテンツの有効化」を押してマクロを有効にする
  * ボタンが反応しない場合は、エクスプローラーでブックのプロパティを開き、
    「セキュリティ: 許可する」にチェックを入れてから開き直す

■ 以下、`{ブックのフォルダー}` はコピーしたブックがあるフォルダーに読み替える。

■ テストの途中でブックを保存しないこと。各テストは、コピーしたての状態から始める。
  続けて行う場合は、保存せずに閉じて、もう一度コピーし直す。

## 自動テスト

* リポジトリのルートの PowerShell で以下を実行する
  ```
  pwsh -File tools\parameter-sheet\test-parameter-sheet.ps1
  ```
  * [ ] 最後に「すべて成功しました。」と表示されること

■ 自動テストは、出力する JSON の内容と入力チェックを、Excel の画面を使わずに確認する。
  以下の手順では、ボタン・ダイアログ・入力規則・出力ファイルなど、画面操作を伴う部分を確認する。

### 入力規則

* 「監査ログ (NetLogger)」シートの「この機能を有効にする」の「値」セルを選択する
  * [ ] プルダウンが表示され、選択肢が「有効」「無効」の 2 つであること
* 「使用時間の制限 (UsageTimeLimit)」シートの「上限を超えたときの動作」の「値」セルを選択する
  * [ ] プルダウンが表示され、選択肢が「警告のみ」「ブラウザーを終了する」の 2 つであること
* 「監査ログ (NetLogger)」シートの「ログの保持日数」の「値」セルに、以下をそれぞれ入力する
  * `-1`
    * [ ] Excel の入力規則のエラーが表示され、入力できないこと
  * `1.5`
    * [ ] Excel の入力規則のエラーが表示され、入力できないこと
  * `abc`
    * [ ] Excel の入力規則のエラーが表示され、入力できないこと
  * `0`
    * [ ] 入力できること
* 同様に、以下の「値」セルでも `-1` が入力できないことを確認する
  * [ ] 「監査ログ (NetLogger)」の「1 日あたりのファイル最大サイズ (MB)」「保留ファイルの最大サイズ (MB)」「再送の間隔 (分)」
  * [ ] 「使用時間の制限 (UsageTimeLimit)」の「連続して使える時間の上限 (分)」「終了するまでの猶予 (秒)」「再警告の間隔 (分)」
  * [ ] 「タブ数の上限 (TabCountLimit)」の「同時に開けるタブの数」
  * [ ] 「アップロードの控え (UploadFileBridge)」の「控えを残すファイルの最大サイズ (MB)」
* 「アップロード制御 (UploadGuard)」シートの「ブロックする拡張子」の表で、最終行（10 行目）を選択して Tab キーを押す
  * [ ] 表に行が 1 行追加されること
* 「使用時間の制限 (UsageTimeLimit)」シートの「利用を許可する時間帯」の「開始時刻」に `9:00` と入力する
  * [ ] 時刻として変換されず、`9:00` という文字列のまま表示されること（セルが文字列の書式であるため）
  * ※文字列のままでも、出力時に `09:00` にそろえられる（「値を指定してのエクスポート」で確認する）
* 変更を保存せずにブックを閉じる

### 初期値のエクスポート

#### 準備

* 「準備」の手順で、コピーしたてのブックを開く

#### テスト

* 「エクスポート」シートを開く
  * [ ] 「パラメータシートの内容を設定ファイルとして出力する」ボタンが表示されていること
* 「パラメータシートの内容を設定ファイルとして出力する」ボタンを押す
  * [ ] タイトルが「確認」のダイアログが表示されること
  * [ ] 以下のメッセージが表示されること
    ```
    {ブックのフォルダー}\BrowserGuard_export
    に現在の設定を BrowserGuard.json として出力します。よろしいですか？
    ```
* ダイアログの「キャンセル」ボタンを押す
  * [ ] 設定ファイルが出力されないこと
  * [ ] `{ブックのフォルダー}\BrowserGuard_export` フォルダーが作成されていないこと
* 再度「パラメータシートの内容を設定ファイルとして出力する」ボタンを押す
* ダイアログの「OK」ボタンを押す
  * [ ] タイトルが「完了」のダイアログが表示されること
  * [ ] 以下のメッセージが表示されること
    ```
    出力しました。

    {ブックのフォルダー}\BrowserGuard_export\{現在時刻}\BrowserGuard.json
    ```
* `{ブックのフォルダー}\BrowserGuard_export\{現在時刻}` フォルダーを確認する。
  ここで `{現在時刻}` は `{4桁の年}{2桁の月}{2桁の日}_{2桁の時}{2桁の分}{2桁の秒}` という形式である。
  * [ ] `BrowserGuard.json` が出力されていること
* 出力された `BrowserGuard.json` について、PowerShell で以下を実行する
  ```
  $repo = '.'   # リポジトリのパスに読み替える
  $file = '{ブックのフォルダー}\BrowserGuard_export\{現在時刻}\BrowserGuard.json'
  $bytes = [IO.File]::ReadAllBytes($file)
  'BOM: ' + ($bytes.Length -ge 3 -and $bytes[0] -eq 0xEF -and $bytes[1] -eq 0xBB -and $bytes[2] -eq 0xBF)
  $exported = (Get-Content -Raw -Encoding UTF8 $file) -replace "`r`n", "`n"
  $expected = (Get-Content -Raw -Encoding UTF8 "$repo\Resources\BrowserGuard.json") -replace "`r`n", "`n"
  'Same as Resources: ' + ($exported.Trim() -eq $expected.Trim())
  ```
  * [ ] `BOM: False` と表示されること（BOM なしの UTF-8 であること）
  * [ ] `Same as Resources: True` と表示されること
    * ※改行コードは、出力ファイルが CRLF、`Resources\BrowserGuard.json` が LF のため、比較時にそろえている

■ 初期値の出力が `Resources\BrowserGuard.json`（インストーラーが配置する設定ファイル）と一致することで、
  パラメータシートの初期値と製品の既定の設定が食い違っていないことを確認する。

##### 有効・無効の欄

* 「設定ページの遮断 (SettingPageFilter)」シートの「ブロック時に通知を表示する」の「値」セルを選択し、Delete キーで空欄にする
* 「エクスポート」シートで出力し、「OK」を押す
  * [ ] 入力エラーにならず、出力されること
* 出力された `BrowserGuard.json` を確認する
  * [ ] `SettingPageFilter` の `NotifyOnBlocked` が `false` であること（空欄は「無効」として扱われる）

##### 数値の欄

* 「タブ数の上限 (TabCountLimit)」シートの「同時に開けるタブの数」の「値」セルを選択し、Delete キーで空欄にする
* 「監査ログ (NetLogger)」シートの「ログの保持日数」の「値」セルを選択し、Delete キーで空欄にする
* 「エクスポート」シートで「パラメータシートの内容を設定ファイルとして出力する」ボタンを押す
  * [ ] タイトルが「入力エラー」のダイアログが表示されること
  * [ ] 以下のメッセージが表示されること
    ```
    入力内容に問題があります。修正してから再実行してください。

    ・監査ログ: LocalFile.MaxDays が空欄です。0 以上の整数を入力してください。
    ・タブ数の上限: MaxCount が空欄です。0 以上の整数を入力してください。
    ```
* ダイアログの「OK」ボタンを押す
  * [ ] タイトルが「確認」のダイアログが表示**されない**こと
* 変更を保存せずにブックを閉じる

■ 数値の欄を空欄のまま出力すると `0` になり、「ログの保持日数」の `0`（無期限に保存）のように
  意味が変わってしまう。そのため、数値の空欄は入力エラーにしている。

### 入力エラー

#### 準備

* 「値を指定してのエクスポート」の「テスト」の値の指定までを行っておく（出力はしなくてよい）

#### テスト

* 以下のように値を変更する
  * 「監査ログ (NetLogger)」
    * 「送信先エンドポイント」: Delete キーで空欄にする
    * 「ログの保持日数」: 任意の空いているセルに `-1` と入力してコピーし、「値」セルに貼り付ける
      * ※直接入力すると入力規則で拒否されるため、貼り付けで入力規則を回避する
  * 「アップロードの控え (UploadFileBridge)」
    * 「控えの保存先」: Delete キーで空欄にする
  * 「使用時間の制限 (UsageTimeLimit)」
    * 「上限を超えたときの動作」: Delete キーで空欄にする
    * 「終了するまでの猶予 (秒)」: Delete キーで空欄にする
    * 「利用を許可する時間帯」の表の 1 行目の「開始時刻」: `9時`
    * 「利用を許可する時間帯」の表の 3 行目: 「開始時刻」を `0900`、「終了時刻」を `10:00`
    * 「利用を許可する時間帯」の表の 4 行目: 「開始時刻」を `9:00`、「終了時刻」を `10:00`
      * ※4 行目は正しい入力であり、エラーにならないことを確認するためのもの
  * 「タブ数の上限 (TabCountLimit)」
    * 「同時に開けるタブの数」: 任意の空いているセルに `abc` と入力してコピーし、「値」セルに貼り付ける
  * 「起動時プログラム実行 (StartupLauncher)」
    * 「実行するプログラム」の表の 5 行目の「引数」: `--only-args`（実行ファイルのパスは空欄のまま）
* 「エクスポート」シートを開き、「パラメータシートの内容を設定ファイルとして出力する」ボタンを押す
  * [ ] タイトルが「入力エラー」のダイアログが表示されること
  * [ ] 以下のメッセージが表示されること
    ```
    入力内容に問題があります。修正してから再実行してください。

    ・監査ログ: LocalFile.MaxDays には 0 以上の整数を入力してください。
    ・使用時間の制限: OnExceeded.GraceSeconds が空欄です。0 以上の整数を入力してください。
    ・タブ数の上限: MaxCount には数値を入力してください。
    ・監査ログ: 送信を有効にする場合は送信先エンドポイントが必要です。
    ・アップロードの控え: 有効にする場合は保存先が必要です。
    ・使用時間の制限: 「上限を超えたときの動作」は「警告のみ」または「ブラウザーを終了する」から選んでください。
    ・起動時プログラム実行: 5 行目に実行ファイルのパスがありません。
    ・使用時間の制限: 1 行目の時刻は H:mm または HH:mm 形式で入力してください。
    ・使用時間の制限: 3 行目の時刻は H:mm または HH:mm 形式で入力してください。
    ```
    * ※「N 行目」は、シートの行番号ではなく、表の見出しを除いた何行目かを表す
    * [ ] 4 行目（`9:00`）についてのエラーが表示**されない**こと
* ダイアログの「OK」ボタンを押す
  * [ ] タイトルが「確認」のダイアログが表示**されない**こと
  * [ ] `{ブックのフォルダー}\BrowserGuard_export` に新しいフォルダーが作成されていないこと
* メッセージに従って、変更した値をすべて「値を指定してのエクスポート」の値に戻す
  * 「利用を許可する時間帯」の 3 行目と 4 行目は、開始時刻・終了時刻とも空欄にする
  * 「実行するプログラム」の 5 行目の「引数」は空欄にする
* 再度「パラメータシートの内容を設定ファイルとして出力する」ボタンを押す
  * [ ] タイトルが「確認」のダイアログが表示されること（入力エラーが解消されていること）
* 「キャンセル」を押し、変更を保存せずにブックを閉じる

■ 時刻は `H:mm` または `HH:mm` で入力できる（Chronos BrowserGuard 本体と同じ）。
  セルは文字列の書式のため `9:00` と入力しても時刻には変換されないが、出力時に `09:00` にそろえられる。
  `0900` のように `:` のないものや、`9時` のような書式は入力エラーになる。
