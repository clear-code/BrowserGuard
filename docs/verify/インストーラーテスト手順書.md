# BrowserGuard セットアップのWindows向けテスト手順

## 準備

* テスト環境: Windows 11（x64）
  * **ドメインに参加していない端末**を使用すること
    * グループポリシーで「拡張機能の管理設定を構成する」（`ExtensionSettings`）が構成されていると、
      `gpupdate` のたびに上書きされ、ポリシー登録の結果を確認できないため
  * 管理者権限を持つユーザーで実施すること
* .NET SDK 8 以上をインストール
  * https://dotnet.microsoft.com/ja-jp/download
* Node.js 20 以上をインストール
  * https://nodejs.org/
* Inno Setup 6 をインストール
  * https://jrsoftware.org/isinfo.php
* Microsoft Edge をインストール
  * 拡張機能の crx の作成に使用する
* リリース用の署名鍵を `webextensions\pem\edge.pem` に配置する
  * 配置しないとビルドスクリプトがエラー終了する

■ 以下、`{バージョン番号}` は `BrowserGuard.iss` の `AppVersion` の値（例：`1.0.0.0`）に読み替える。

■ MSI の ProductCode はバージョンごとに変わる。
  確認には、以下のコマンドで `BrowserGuard.iss` から取り出した値を使う（リポジトリのルートの PowerShell で実行する）。

```
$code = (Select-String -Path .\BrowserGuard.iss -Pattern "MsiProductCode = '(.+)'").Matches[0].Groups[1].Value
Test-Path "HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall\$code"
```

* `True` であれば MSI パッケージがインストールされている、`False` であればされていない。
  以下、この確認を「MSI パッケージの登録確認」と呼ぶ。

## セットアップのビルドスクリプト検証

* リポジトリのルートで `make.bat` を実行する
* [ ] `=== 1/5 Publishing BrowserGuard ===` から `=== 5/5 Building the MSI package ===` まで順に実行され、
      最後に `Build completed.` と表示されること
* [ ] `SetupOutput\BrowserGuardSetup-{バージョン番号}.exe` が作成されること
* [ ] `SetupOutput\msi\ja\BrowserGuardSetup-{バージョン番号}.msi` が作成されること
* `SetupOutput\BrowserGuardSetup-{バージョン番号}.exe` を右クリックし、[プロパティ] → [詳細] を開く
  * [ ] 「ファイル バージョン」「製品バージョン」が `{バージョン番号}` であること

### 署名鍵がない場合

* `webextensions\pem\edge.pem` を一時的に別の場所へ移動する
* `make.bat` を実行する
  * [ ] `Build failed: the extension signing key was not found.` と表示され、エラー終了すること
  * [ ] ビルドが実行されないこと（`=== 1/5 ...` が表示されないこと）
* `webextensions\pem\edge.pem` を元の場所に戻す

## exeセットアップ動作検証

### 新規インストール（パラメータ指定なし）

#### 準備

* 既に BrowserGuard がインストールされている場合はアンインストールする

  ```
  * 何も表示されなければよい
* Edge を起動し、任意のページを開いておく

#### テスト

##### ファイルが正しくインストールされていることの確認

* `C:\Program Files\BrowserGuard` を開く
  * [ ] `BrowserGuard.json` が存在すること
    * [ ] 内容がリポジトリの `Resources\BrowserGuard.json` と一致すること
  * [ ] `BrowserGuardHost\` フォルダー配下に以下のファイルが存在すること
    * `BrowserGuard.exe`
    * `edge.json`
  * [ ] `BrowserGuardExtension\` フォルダー配下に以下のファイルが存在すること
    * `BrowserGuardEdge.crx`
    * `manifest.xml`
  * [ ] `unins000.exe` が存在すること
* `BrowserGuardExtension\manifest.xml` をテキストエディターで開く
  * [ ] `codebase` が以下のとおりであること（`{InstallFolder}` が置き換えられていること）
    ```
    file:///C:/Program%20Files/BrowserGuard/BrowserGuardExtension/BrowserGuardEdge.crx
    ```
  * [ ] `appid` が `ddniogodiahgpmfkljajobgkaecabnif` であること
* `BrowserGuardHost\edge.json` をテキストエディターで開く
  * [ ] `name` が `com.clear_code.browser_guard` であること
  * [ ] `path` が `BrowserGuard.exe` であること
  * [ ] `allowed_origins` が `chrome-extension://ddniogodiahgpmfkljajobgkaecabnif/` であること

##### アクセス権の確認

* 管理者権限のコマンドプロンプトで以下を実行する
  ```
  icacls "C:\Program Files\BrowserGuard\BrowserGuardHost\BrowserGuard.exe"
  icacls "C:\Program Files\BrowserGuard\BrowserGuardHost\edge.json"
  ```
  * それぞれについて
    * [ ] `BUILTIN\Users:(RX)` があること（一般ユーザーは読み取りと実行のみ）
    * [ ] `BUILTIN\Administrators:(F)` があること
    * [ ] `NT AUTHORITY\SYSTEM:(F)` があること
    * [ ] 継承されたアクセス許可（`(I)` の付いた行）が**ない**こと
* 以下を実行する
  ```
  icacls "C:\Program Files\BrowserGuard\BrowserGuard.json"
  ```
  * [ ] `BUILTIN\Users` が読み取りと実行（`(I)(RX)`）のみであること
  * [ ] `BUILTIN\Users`、`NT AUTHORITY\Authenticated Users`、`Everyone` のいずれにも、
        変更（`(M)`）、書き込み（`(W)`）、フル コントロール（`(F)`）の権限が**ない**こと
  * [ ] `BUILTIN\Administrators:(I)(F)` と `NT AUTHORITY\SYSTEM:(I)(F)` があること
  * ※インストーラーは設定ファイルのアクセス権を変更せず、`C:\Program Files` から引き継ぐ。
    管理者だけが変更できることを確認する
* 管理者権限**ではない**メモ帳で `C:\Program Files\BrowserGuard\BrowserGuard.json` を開き、
  任意の文字を追加して上書き保存する
  * [ ] アクセスが拒否され、保存できないこと

##### レジストリの確認

* 管理者権限のコマンドプロンプトで以下を実行する
  ```

  ```
  * [ ] `Path` が `C:\Program Files\BrowserGuard\` であること

  ```
  * [ ] 既定値が `C:\Program Files\BrowserGuard\BrowserGuardHost\edge.json` であること
* 以下を実行する
  ```
  reg query "HKLM\SOFTWARE\Policies\Microsoft\Edge" /v ExtensionSettings
  ```
  * [ ] 値が見つからない旨が表示されること（ポリシーが登録されていないこと）

##### アプリ一覧の確認

* Windowsの [アプリ] -> [インストールされているアプリ] を開く
  * [ ] 「BrowserGuard」のエントリが一つだけ存在すること
  * [ ] バージョンが `{バージョン番号}` であること
* MSI パッケージの登録確認を行う

### 新規インストール（ポリシー登録あり）

#### 目的

タスクを選択したとき、`ExtensionSettings` に拡張機能が登録されること、
および既存の他の拡張機能の設定が保持されることを確認する。

#### 準備

* 既に BrowserGuard がインストールされている場合はアンインストールする
* 管理者権限の PowerShell で以下を実行し、他の拡張機能の設定を模したダミーの項目を登録する
  ```
  New-Item -Path HKLM:\SOFTWARE\Policies\Microsoft\Edge -Force | Out-Null
  Set-ItemProperty -Path HKLM:\SOFTWARE\Policies\Microsoft\Edge -Name ExtensionSettings -Value '{"aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa":{"installation_mode":"blocked"}}'
  ```

#### テスト

##### インストール動作検証

* `SetupOutput\BrowserGuardSetup-{バージョン番号}.exe` をダブルクリックする
* [追加タスクの選択] 画面まで [次へ] で進む
* 「拡張機能を Edge のポリシーに登録して自動的にインストールする」にチェックを入れる
  * [ ] チェックできること
* [次へ] を押し、[インストール] を押す
* [ ] インストールが成功すること
* セットアップを終了する

##### ポリシーの確認

* 管理者権限の PowerShell で以下を実行する
  ```
  (Get-ItemProperty -Path HKLM:\SOFTWARE\Policies\Microsoft\Edge).ExtensionSettings
  ```
  * [ ] `ddniogodiahgpmfkljajobgkaecabnif` をキーとする項目が追加されていること
  * [ ] その項目の `installation_mode` が `force_installed` であること
  * [ ] その項目の `update_url` が `file:///C:/Program%20Files/BrowserGuard/BrowserGuardExtension/manifest.xml` であること
  * [ ] その項目の `override_update_url` が `true` であること
  * [ ] 準備で登録した `aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa` の項目が、そのまま残っていること
* 以下を実行する
  ```
  reg query "HKLM\SOFTWARE\BrowserGuard" /v ExtensionSettingsRegistered
  ```
  * [ ] 値が `1` であること

##### 拡張機能がインストールされることの確認

* Edge を起動する
* `edge://policy` を開く
  * [ ] `ExtensionSettings` が表示され、エラーがないこと
* `edge://extensions` を開く
  * [ ] 「BrowserGuard」が表示され、有効であること
  * [ ] 管理者によって管理されている旨が表示され、削除・無効化ができないこと
  * ※表示されない場合は、開発者モードをオンにして [更新] を押す

■ 拡張機能とホストの通信など、インストール後の動作は `連結テスト手順書.md` で確認する。

### 新規インストール（パラメータ指定＋VERYSILENT）

#### 目的

VERYSILENT を指定したとき、画面が表示されない状態でインストールされ、
`/TASKS` の指定に従ってポリシー登録の有無が決まることを確認する。

* 管理者権限の PowerShell で以下を実行し、`ExtensionSettings` を削除しておく

#### テスト

  * `echo %ERRORLEVEL%` を実行し、値が `0` であればよい
* 以下を実行する
  ```
  reg query "HKLM\SOFTWARE\Policies\Microsoft\Edge" /v ExtensionSettings
  ```
  * [ ] 値が見つからない旨が表示されること（ポリシーが登録されていないこと）

##### タスクの指定あり

* 管理者権限でコマンドプロンプトを起動する
* `SetupOutput` に移動する

* [ ] セットアップの画面が表示**されない**こと
* [ ] インストールが成功すること
  * `echo %ERRORLEVEL%` を実行し、値が `0` であればよい
* 「新規インストール（ポリシー登録あり）」の「ポリシーの確認」と同じ確認を行う

  * [ ] `ExtensionSettingsRegistered` が `1` であること

■ VERYSILENT は Inno Setup 自体の機能であり、独自の部分はタスクの反映のみである。
  以上から、コマンドが成功し、タスクの指定どおりにポリシーが登録されていればよい。

### バージョンアップ（MSI）

#### 目的

新しいバージョンの MSI を、旧バージョンの MSI の上からそのままインストールできること
（事前のアンインストールが不要であること）を確認する。

#### 準備

* 既に BrowserGuard がインストールされている場合はアンインストールする
* 現在のバージョンで `make.bat` を実行し、作成された MSI を別のフォルダーに退避する
  * 以下、退避したものを「旧 MSI」と呼ぶ
* リポジトリのルートの PowerShell で、旧バージョンの ProductCode を控える
  ```
  $oldCode = (Select-String -Path .\BrowserGuard.iss -Pattern "MsiProductCode = '(.+)'").Matches[0].Groups[1].Value
  ```
* 同じ PowerShell で、バージョンを上げて再度ビルドする
  ```
  .\bump-version.ps1 {新バージョン}
  .\make.bat
  ```
  * 以下、作成されたものを「新 MSI」と呼ぶ

#### テスト

* 旧 MSI を `msiexec /i` でインストールする
* `C:\Program Files\BrowserGuard\BrowserGuard.json` をテキストエディターで開き、
  `"TabCountLimit"` の `"MaxCount"` を `7` に変更して保存する
* Edge を終了する
* 新 MSI を `msiexec /i` でインストールする
  * [ ] インストーラーが正常終了すること
  * [ ] Inno Setup の exe のインストーラーが表示**されない**こと
* Windowsのアプリ一覧を開く
  * [ ] 「BrowserGuard」のエントリが一つだけ存在していること
  * [ ] バージョンが `{新バージョン}` であること
* 準備で使った PowerShell で以下を実行する
  ```
  Test-Path "HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall\$oldCode"
  ```
  * [ ] `False` であること（旧 MSI パッケージが削除されていること）
* MSI パッケージの登録確認を行う（バージョンを上げた後の `BrowserGuard.iss` の値で確認する）
  * [ ] `True` であること
* [ ] `reg query "HKLM\SOFTWARE\BrowserGuard" /v Version` の値が `{新バージョン}` であること
* [ ] `C:\Program Files\BrowserGuard\BrowserGuard.json` の `"MaxCount"` が `7` のままであること
* [ ] `C:\Program Files\BrowserGuard\BrowserGuardHost\BrowserGuard.exe` が存在すること
  * ※旧 MSI の削除に連動して exe 版がアンインストールされていないことの確認
