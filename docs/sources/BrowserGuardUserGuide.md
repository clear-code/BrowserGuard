# BrowserGuardとは

BrowserGuard for Edge（以下、BrowserGuard）は、業務で使用するMicrosoft Edgeの操作を、
組織の方針に沿って制限・記録するための拡張機能です。

BrowserGuardはシステム管理者によって配布され、Edgeのポリシーによって自動的にインストールされます。
利用者が導入したり、取り外したりする操作は必要ありません。

## 主な機能

* **ファイルのアップロードを制限します。**
  組織の方針で許可されていない拡張子や、持ち出しが禁止された場所のファイルをアップロードしようとすると、
  警告のダイアログが表示され、送信が取り消されます。
* **アップロードしたファイルの控えを残します。**
  アップロードされたファイルは、システム管理者が指定した保管先へ自動的にコピーされます。
* **ブラウザーの設定ページへのアクセスを制限します。**
  `edge://settings` などの設定ページを開こうとすると、直前に見ていたページへ戻されます。
* **同時に開けるタブの数を制限します。**
  上限を超えてタブを開こうとすると、開いたタブが自動的に閉じられます。
* **使用時間を制限します。**
  連続して使用できる時間や、使用できる時間帯を超えると警告が表示されます。
  設定によっては、猶予時間の経過後にブラウザーが自動的に終了します。
* **操作の記録（監査ログ）を残します。**
  ページの表示、アップロード、ダウンロード、印刷などの操作が記録されます。
* **ブラウザーの起動時に、指定されたプログラムを実行します。**

どの機能が有効になっているか、どのような条件で制限されるかは、システム管理者の設定によって決まります。
本ガイドの説明のうち、有効になっていない機能については読み飛ばしてください。

# 表示される警告

BrowserGuardの警告は、Edgeの画面ではなく、**「BrowserGuard」というタイトルのダイアログ**として表示されます。
ダイアログには「OK」ボタンだけがあり、クリックすると閉じます。

■ ダイアログを閉じても、制限そのものは取り消されません。
アップロードの中止やタブの終了は、ダイアログの操作とは関係なく行われます。

## アップロードがブロックされました

ファイルのアップロードが、組織の方針により許可されなかった場合に表示されます。

```
アップロードがブロックされました:
C:\Users\example\Documents\report.exe

理由: 禁止された拡張子です
```

「理由」には次のいずれかが表示されます。

| 理由 | 意味 |
| --- | --- |
| 禁止された拡張子です | その拡張子のファイルは、アップロードが禁止されています |
| 許可された拡張子ではありません | アップロードが許可された拡張子の一覧に含まれていません |
| アップロードが禁止された場所のファイルです | そのフォルダーのファイルは、持ち出しが禁止されています |
| アップロードが許可されていない場所のファイルです | アップロードが許可されたフォルダーの外にあります |

### アップロードが中止されたときの画面

* **フォームの送信ボタンを押した場合** … 直前に見ていたページに戻ります。エラーページは表示されません。
* **ページ内で送信が行われる場合**（画面が切り替わらないアップロード） … 送信が失敗したものとして扱われます。
  サイト側に「アップロードに失敗しました」といった表示が出ることがあります。

### 複数のファイルを同時に送った場合

1つのファイルでも許可されなかった場合、**そのとき送ろうとしたファイルはすべて送信されません**。
許可される種類のファイルを一緒に選んでいた場合も、あわせて中止されます。
不要なファイルを外して、もう一度操作してください。

## アクセスがブロックされました

ブラウザーの設定ページなど、閲覧が許可されていないアドレスを開こうとした場合に表示されます。

```
アクセスがブロックされました:
edge://settings/

拡張機能のポリシーにより、このページは表示できません。
```

このとき、タブは**直前に見ていたページに戻ります**。
新しいタブから直接そのアドレスを開いた場合は、戻る先がないため、タブは空白のページになります。

## 同時に開くことのできるタブの数は N 個までです

開いているタブの数が上限に達している状態で、さらにタブを開こうとした場合に表示されます。
**新しく開いたタブが自動的に閉じられ**、それまでのタブはそのまま残ります。

* タブの数は、ウィンドウを分けていても合算して数えられます。
* 前回終了時のタブを復元して上限を超えた場合も、超えた分のタブが閉じられます。

■ 新しいタブページ（何も開いていないタブ）は、いったん空白のページに切り替えてから閉じられるため、
閉じられるまでに一瞬の間があります。

## 使用時間に関する警告

次のいずれかの場合に表示されます。

```
連続して使用できる時間の上限に達しました。
作業中の内容を保存して、ブラウザーを終了してください。
```

```
使用が許可された時間帯を過ぎています。
作業中の内容を保存して、ブラウザーを終了してください。
```

* **連続して使用できる時間の上限に達しました。** … ブラウザーを起動してからの経過時間が上限を超えました。
* **使用が許可された時間帯を過ぎています。** … 現在の時刻が、使用を許可された時間帯の外です。

警告だけが表示される設定の場合、ブラウザーは終了しません。
制限を超えている間は、一定の間隔で同じ警告が繰り返し表示されます。

### ブラウザーが自動的に終了する設定の場合

終了する設定になっている場合は、ダイアログに終了予定の時刻が表示されます。

```
連続して使用できる時間の上限に達しました。
18:30:15 にブラウザーを終了します。
作業中の内容をすぐに保存してください。
```

**表示された時刻になると、すべてのウィンドウが閉じられます。**
ダイアログを閉じたかどうかは関係ありません。
表示されている時刻までに、作業中の内容を保存してください。

# 記録される内容

システム管理者の設定により、次の操作が監査ログとして記録されます。

| 記録される操作 | 内容 |
| --- | --- |
| ページの表示 | 表示したページのアドレスとタイトル |
| 通信先のアドレス | ページの表示に伴って通信した先 |
| アップロード | 送信したファイルの名前と送信先 |
| ダウンロード | 保存したファイルのパスと取得元 |
| 印刷 | 印刷したページのアドレスとタイトル |
| ブロックされたアップロード | 送信しようとしたファイルのパス、送信先、ブロックされた理由 |

いずれの記録にも、操作した日時、コンピューター名、ユーザー名が付きます。
ユーザーの表示名（取得できる場合）と、Windows のセッション番号も付きます。

■ ブロックされたアップロードは、アップロードの記録を行わない設定であっても記録されます。

## 記録の例

監査ログは、1 行に 1 件の操作を JSON 形式で記録したテキストファイル（`netlog.jsonl`）です。
以下は、ページの表示、ファイルのアップロードとダウンロード、印刷、
ブロックされたアップロードを行ったときの記録の例です。

```json
{"operation":"browsing","name":"社内ポータル","url":"https://portal.example.jp/","timestamp":"2026-09-07 10:12:33","host":"PC-0123","user":"EXAMPLE\\taro","user_displayName":"山田 太郎","session":1}
{"operation":"urlaccess","name":"portal.example.jp","url":"https://portal.example.jp/","timestamp":"2026-09-07 10:12:33","host":"PC-0123","user":"EXAMPLE\\taro","user_displayName":"山田 太郎","session":1}
{"operation":"upload","name":"見積書.xlsx","url":"https://files.example.jp/upload","timestamp":"2026-09-07 10:14:05","host":"PC-0123","user":"EXAMPLE\\taro","user_displayName":"山田 太郎","session":1}
{"operation":"download","name":"C:\\Users\\taro\\Downloads\\manual.pdf","url":"https://portal.example.jp/docs/manual.pdf","timestamp":"2026-09-07 10:20:41","host":"PC-0123","user":"EXAMPLE\\taro","user_displayName":"山田 太郎","session":1}
{"operation":"print","name":"社内ポータル","url":"https://portal.example.jp/","timestamp":"2026-09-07 10:25:10","host":"PC-0123","user":"EXAMPLE\\taro","user_displayName":"山田 太郎","session":1}
{"operation":"upload-guard","name":"C:\\Users\\taro\\Desktop\\tool.exe","url":"https://files.example.jp/upload","timestamp":"2026-09-07 10:30:02","reason":"blockedExtension","host":"PC-0123","user":"EXAMPLE\\taro","user_displayName":"山田 太郎","session":1}
```

各項目の意味は次のとおりです。

| 項目 | 内容 |
| --- | --- |
| `operation` | 操作の種類（下表） |
| `name` | ページのタイトル、ファイル名、通信先のホスト名など |
| `url` | 表示したページ、送信先、取得元などのアドレス |
| `timestamp` | 操作した日時 |
| `reason` | ブロックされた理由（ブロックされたアップロードの場合のみ） |
| `host` | コンピューター名 |
| `user` | `ドメイン名\ユーザー名` 形式のユーザー名 |
| `user_displayName` | ユーザーの表示名。取得できない場合は記録されません |
| `session` | Windows のセッション番号 |

| `operation` | 操作 |
| --- | --- |
| `browsing` | ページの表示 |
| `urlaccess` | 通信先のアドレス |
| `upload` | アップロード |
| `download` | ダウンロード |
| `print` | 印刷 |
| `upload-guard` | ブロックされたアップロード |

`reason` には、ダイアログに表示された理由に対応する次の値が記録されます。

| `reason` | ダイアログに表示される理由 |
| --- | --- |
| `blockedExtension` | 禁止された拡張子です |
| `extensionNotAllowed` | 許可された拡張子ではありません |
| `blockedPath` | アップロードが禁止された場所のファイルです |
| `pathNotAllowed` | アップロードが許可されていない場所のファイルです |

■ ファイルのパスなどに含まれる `\` は、JSON の書式上 `\\` と記録されます。

■ 1 回のページ表示で、ページ内の画像やスクリプトの取得ごとに
  `urlaccess` の記録が複数残ることがあります。

また、アップロードしたファイルそのものが、システム管理者の指定した保管先へコピーされる場合があります。

どの操作が記録されるか、記録がどこへ送られるかは、システム管理者の設定によって決まります。
記録の内容や取り扱いについては、システム管理者へお問い合わせください。

# 設定について

BrowserGuardの設定は、**システム管理者が管理します。利用者が変更することはできません。**

設定はコンピューター内の設定ファイルに保存されており、その場所はレジストリの
`HKEY_LOCAL_MACHINE\SOFTWARE\BrowserGuard` の `Configfile` が示しています。
既定では `C:\Program Files\BrowserGuard\BrowserGuard.json` です。

制限の内容を変更したい場合や、業務上必要な操作が妨げられている場合は、
システム管理者へお問い合わせください。

## 拡張機能が有効になっていることを確認する

`edge://extensions` を開くと、BrowserGuardが一覧に表示されます。

* 「BrowserGuard」が表示され、有効になっていること
* 「このアドオンは管理者によって管理されています」といった表示があり、削除や無効化ができないこと

■ 設定ページの遮断が有効な場合、`edge://extensions` 自体が開けないことがあります。
その場合はシステム管理者へお問い合わせください。

# FAQ（よくある質問）

## BrowserGuardを削除したり、無効にしたりできません

BrowserGuardは、組織のポリシーによって強制的にインストールされています。
仕様上、利用者の操作で削除・無効化することはできません。

業務上必要な場合は、システム管理者へお問い合わせください。

## アップロードしようとしたら、警告も出ずに元のページに戻りました

別の警告のダイアログが表示されている間は、後から発生した警告は表示されません。
このとき、アップロードの中止そのものは行われています。

表示されているダイアログを閉じてから、もう一度操作してください。

## 設定ページを開いたら、真っ白なページになりました

閲覧が許可されていないアドレスを、新しいタブから直接開いた場合の動作です。
戻る先のページがないため、空白のページになります。異常ではありません。

## 予告なくブラウザーが終了しました

使用時間の制限により終了した可能性があります。
終了の前には、終了予定の時刻を示したダイアログが表示されます。

ダイアログに気づかないまま時間が経過すると、予告を見ないまま終了したように見えることがあります。
心当たりのない終了が繰り返される場合は、システム管理者へお問い合わせください。

## タブが勝手に閉じられました

同時に開けるタブの数が上限に達しています。
上限の数は、表示されるダイアログの文面で確認できます。

## 警告が表示されなくなりました

BrowserGuardは、拡張機能と、コンピューター内で動作する専用のプログラムが連携して動作します。
この連携ができなくなった場合、ブラウザーの操作は妨げられませんが、制限や記録は行われません。

ブラウザーの動作に問題がなくても、本来ブロックされるはずの操作が通ってしまう場合は、
制限が効いていない可能性があります。システム管理者へお問い合わせください。

## ブラウザーの起動時に、身に覚えのないプログラムが起動します

システム管理者が、ブラウザーの起動に合わせて実行するプログラムを設定している場合があります。
どのプログラムが設定されているかは、システム管理者へお問い合わせください。

## 制限の内容を変更したい

システム管理者へお問い合わせください。設定ファイルは管理者権限で管理されており、
利用者による変更は想定されていません。

# 制限事項

* BrowserGuardが制限できるのは、**Microsoft Edge上での操作だけ**です。
  他のブラウザーや、ブラウザー以外のアプリケーションからのファイルの送信は対象外です。
* 警告のダイアログは、同時に1つだけ表示されます。
  表示中に別の警告が発生した場合、その警告は表示されません。
  ただし、制限そのもの（アップロードの中止、タブを閉じる等）は行われます。
* アップロードは、送信しようとしたファイルのうち1つでも許可されなかった場合、
  そのとき送ろうとしたファイル全体が送信されません。
* 使用時間の判定は1分ごとに行われます。
  制限を超えてから警告が表示されるまでに、最大で1分程度の間があります。
